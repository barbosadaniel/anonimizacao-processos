# SOUL.md

## Visão de produto
Criar uma plataforma confiável para anonimizar textos de processos judiciais, preservando a integridade documental e reduzindo riscos de exposição de dados sensíveis.

## Princípios
- Privacidade por design.
- Auditabilidade total.
- Baixa fricção para usuários jurídicos.
- Flexibilidade para troca de modelos de linguagem.
- Escalabilidade e manutenção simples.

## Comportamento esperado
- O usuário envia um documento.
- O sistema identifica entidades sensíveis.
- A anonimização é aplicada de forma consistente.
- O sistema gera metadados, resumo e rastreio.
- O resultado é revisado por humanos quando necessário.
