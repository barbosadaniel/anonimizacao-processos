# Contrato 07 - Frontend, Usabilidade e Manutenibilidade

## Frontend
- Página de upload simples.
- Visualização do texto anonimizado.
- Lista de entidades detectadas.
- Área de revisão e aprovação.

## Usabilidade
- Fluxo em até 3 passos.
- Feedback visual de progresso.
- Mensagens claras de erro e sucesso.

## Manutenibilidade
- Componentização forte.
- Separação entre camada de API, domínio e infraestrutura.
- Testes automatizados e documentação por contrato.
- Versionamento semântico.
